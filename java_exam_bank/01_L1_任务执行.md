## 四、简答题（每题 5 分，共 25 分）

**23. [L1·语言基础，5 分]** 列出 Java 中至少 5 种常见的「集合容器类」并分别说明它们的核心数据结构与典型用途。

> 参考要点：`ArrayList`（动态数组）、`LinkedList`（双向链表）、`HashMap`（数组+链表/红黑树）、`LinkedHashMap`（保持插入顺序）、`TreeMap`（红黑树有序）、`HashSet`/`TreeSet`、`ArrayDeque` 等。

**24. [L1·OOP，5 分]** 描述「重载（overload）」与「重写（override）」的区别，并各给出一个简短代码示例。

> 参考要点：重载在同一类中方法签名不同；重写在子类中保持签名一致并加 `@Override`；二者作用域、绑定方式不同。

**25. [L1·异常，5 分]** 简述 Java 异常的「检查异常 vs 运行时异常」区别，并各举 2 个典型异常类。

> 参考要点：检查异常（`IOException`、`SQLException`）需 `throws`/try-catch；运行时异常（`NullPointerException`、`IllegalArgumentException`）不强制处理。

**26. [L1·框架认知，5 分]** 用一段话描述 Spring Boot 应用从 `main()` 启动到对外提供 HTTP 服务的大致流程（≥ 4 个步骤）。

> 参考要点：`SpringApplication.run()` → 引导启动器 → 自动装配/扫描组件 → 初始化嵌入式容器（Tomcat/Undertow/Jetty）→ 注册 DispatcherServlet → 处理请求。

**27. [L1·语法，5 分]** 阅读以下代码并指出至少 3 处问题或改进点：
```java
public List getUsers() {
    List list = new ArrayList();
    list.add("alice");
    list.add(123);
    return list;
}
```

> 参考要点：缺少泛型；混入异构元素；返回原始 `List` 类型；命名不规范；可考虑返回不可变集合或 DTO；缺少 `@Nullable` 等说明。
