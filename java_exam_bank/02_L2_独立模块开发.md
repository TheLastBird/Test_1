## 四、简答题（每题 5 分，共 25 分）

**23. [L2·并发，5 分]** 写出一个使用 `ThreadPoolExecutor` 显式构造线程池的代码示例（核心 4、最大 16、有界队列 200、`CallerRunsPolicy`），并解释每个参数选择的考量。

**24. [L2·Spring Boot，5 分]** 描述如何在 Spring Boot 中实现一个「带分页与字段过滤」的 GET 接口（≥ 4 个步骤），可只描述思路与关键代码片段。

> 参考要点：DTO + 校验、参数 `Pageable`、Service 层、Repository/MyBatis 查询、统一响应封装、单测。

**25. [L2·MyBatis，5 分]** 给定一段动态查询 SQL 需要根据「姓名/年龄区间/状态列表」三个可选条件查询用户。请描述使用 MyBatis 实现的关键点（≥ 3 项）。
