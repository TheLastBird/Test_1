# 实操与案例分析题（分级，共 12 题）

> 实操题旨在考核「实际场景下的 Java 编码、调试与工程化」能力。每题给出：场景、输入材料、限时建议、产出物、评分维度。
> 评分采用百分制；建议得分 ≥ 80% 视为该题合格。

---

## L1 实操题（限时 30–60 分钟，工具开放）

### 实操 L1-1：基础工具方法补全
**场景**：在 Maven 项目中已提供 `StringUtils` 模板与一组隐藏单测，需要补全 `isBlank(String s)` 与 `reverse(String s)`。
**任务**：
1. 在 `StringUtils.java` 中实现两个方法，覆盖 `null` 与空串场景；
2. 自行运行 `mvn test` 通过给定单测；
3. 提交时附 200 字内的实现思路与边界用例说明。

**评分维度**（100 分）：
- 单测通过率：50 分
- 边界处理（null / "" / 空白字符）：20 分
- 代码风格与注释：15 分
- 思路与说明：15 分

---

### 实操 L1-2：Spring Boot 最简接口
**场景**：基于 Spring Boot 模板项目，新增 GET `/hello?name=xxx` 接口，返回 `{"message":"hello, xxx"}`。
**任务**：
1. 编写 `HelloController`；
2. 增加一个 JUnit 测试或 `MockMvc` 测试验证响应体；
3. `application.yml` 中将端口设为 `8081`。

**评分维度**（100 分）：
- 接口正确性：40 分
- 测试编写与通过：25 分
- 配置正确性（端口/启动）：15 分
- 代码风格与日志：20 分

### 实操 L1-3：识别并修复 Java 代码缺陷
**场景**：给出两段代码：
```java
// 片段 A：
public int sumLengths(List<String> list) {
    int sum = 0;
    for (String s : list) sum += s.length();
    return sum;
}
// 片段 B：
public String upper(String s) {
    return s.toUpperCase();
}
```
**任务**：
1. 指出至少 1 处潜在 NPE / 健壮性问题；
2. 给出修复后的代码，并补充至少 1 个边界单测。

**评分维度**（50 分）：
- 问题识别：20 分
- 修复正确：20 分
- 单测合理：10 分

## L2 实操题（限时 ≤ 2 小时）

2. 包含字段校验、统一异常处理、统一响应封装；
3. 至少 8 个单元/集成测试用例（含异常路径）；

### 实操 L2-3：缺陷修复挑战

## L3 实操题（限时 ≤ 3 小时）

### 实操 L3-1：并发限流器
**场景**：实现 `RateLimiter`，要求支持令牌桶或漏桶语义，提供 `tryAcquire(int permits, long timeout, TimeUnit unit)`。
**任务**：

2. 支持公平与非公平策略；
3. 提交 JMH 微基准（单线程与多线程）报告；
4. 写一段「线程安全证明」说明（happens-before / 原子性 / 不变量）。

**评分维度**（100 分）：

### 实操 L3-2：分布式接口治理
**场景**：在 Spring Boot + Redis + MQ 上实现下单接口：
- 幂等：基于请求 ID + Redis SETNX；
- 限流：本地 + 分布式（如 Redis Lua）双层；
- 熔断：使用 Resilience4j / Sentinel；
- 异步：MQ 解耦核心链路。
**任务**：
1. 提供完整代码 + 集成测试（可使用 Testcontainers 启动 Redis/RabbitMQ/Kafka）；
2. 输出一份接口设计与时序图；
3. 列出至少 3 个失败场景与降级路径。

**评分维度**（100 分）：
- 幂等/限流/熔断设计：35 分
- 测试可重复性：20 分
- 文档与时序：15 分
- 失败场景与降级：15 分
- 可观测（指标/日志）：15 分
