> 能级目标：理论笔试正确率 ≥ 80%；能进行模块结构设计与并发处理实现；掌握以下核心机制不少于 2 类：JVM 内存模型 / GC 与 JIT / 类加载与字节码 / 并发与锁 / Spring IoC 与 AOP 实现机制 / Netty Reactor 模型 / DJL/ONNX Runtime Java 张量与推理执行机制；在标准测试环境下能完成 ≥ 1 项有效优化（延迟降低 / 吞吐提升 / 内存占用下降）；能在限时案例中独立完成问题定位与修复。
>
> 题型分布：单选 10 + 多选 6 + 判断 6 + 简答 5 + 实操衔接 3。
> 合格线建议：客观题正确率 ≥ 80%，简答题平均得分 ≥ 75%，实操题 ≥ 80%。

## 一、单项选择题（每题 1 分，共 10 分）

**1. [L3·JVM]** 关于 JVM 运行时内存区域，下列说法**最准确**的是：
A. 堆和方法区都是线程私有的
B. 程序计数器、虚拟机栈、本地方法栈是线程私有的；堆与方法区（含运行时常量池/类元数据）是线程共享的
C. 栈和堆都是线程共享的
D. JVM 没有方法区

**2. [L3·GC]** 关于 G1 收集器，下列说法正确的是：
A. G1 是单线程串行收集器
B. G1 将堆划分为多个 Region，按可回收价值优先回收，目标是可控停顿
C. G1 不支持老年代回收
D. G1 仅适用于嵌入式场景

**3. [L3·JMM]** 在 Java 内存模型（JMM）中，下列哪一组关系最能描述「happens-before」？
A. 仅时间先后顺序
B. 程序次序、监视器锁、`volatile` 变量、传递性、`Thread.start/join` 等规则确立的偏序关系
C. 仅与 CPU 缓存相关
D. 仅与 GC 相关

**4. [L3·并发]** 下列关于 `ReentrantLock` 与 `synchronized` 的对比，**最准确**的是：
A. `synchronized` 支持公平锁、可中断、超时获取，`ReentrantLock` 不支持
B. `ReentrantLock` 支持公平/非公平、可中断、超时获取与多个 Condition；`synchronized` 在 JDK 6+ 经过偏向锁/轻量级锁/重量级锁优化但功能少
C. 两者实现原理完全相同
D. `ReentrantLock` 不支持可重入

**5. [L3·Spring 原理]** Spring AOP 在「Bean 是接口实现类」时，默认采用的代理方式通常是：

**7. [L3·Netty]** 关于 Netty 的 Reactor 线程模型，下列说法正确的是：

**8. [L3·Spring Cloud]** 在分布式服务调用中，下列哪种**组合**更适合实现「熔断 + 限流 + 降级」？
A. Hystrix / Resilience4j / Sentinel 等容错组件
B. 仅靠 try-catch

**9. [L3·性能]** 在排查 Java 应用「CPU 飙高」时，下列工具组合**更合适**：

**10. [L3·AI 集成]** 关于在 Java 中调用模型推理（如 ONNX Runtime Java / DJL），下列说法**最准确**的是：

## 四、简答题（每题 5 分，共 25 分）

**23. [L3·JVM/GC，5 分]** 简述「年轻代 GC（Young GC）」、「老年代回收」、「Full GC」的差异；并说明 G1 与 ZGC 在大堆场景下的适用性。

> 参考要点：分代假设；Eden/Survivor；晋升；并发标记/复制；STW 时间；G1 适合中大堆，ZGC 在超大堆与低延迟场景下表现优异。

**24. [L3·并发，5 分]** 描述如何使用 `CompletableFuture` 编排「3 个并行 RPC 调用 + 合并结果」的代码思路（含超时与异常处理）。

> 参考要点：`supplyAsync` + 自定义线程池；`allOf`；`orTimeout`；`exceptionally` / `handle`；超时降级。

**25. [L3·Spring 原理，5 分]** 写一段简短伪代码说明 Spring 中 `@Transactional` 的实现原理（不少于 4 个关键点）。

> 参考要点：基于 AOP 代理；`TransactionInterceptor`；`PlatformTransactionManager` 开启/提交/回滚；同一个类内部调用代理失效；传播行为与隔离级别；编程式与声明式区别。

**26. [L3·性能优化，5 分]** 现象：某 REST 服务 P99 延迟从 80ms 升至 600ms。请给出系统化的排查思路（≥ 5 个步骤）。

> 参考要点：监控基线；定位是 CPU/网络/锁/GC/下游/数据库慢；线程栈与火焰图；连接池/重试风暴；GC 日志；DB 慢 SQL；缓存命中率；同时分析架构与依赖。

**27. [L3·AI 集成，5 分]** 设计一个 Spring Boot 服务，承载 ONNX 模型在线推理。请描述模块结构、并发模型、关键性能点（≥ 5 项）。

> 参考要点：模型加载与单例；推理线程池/批处理；张量复用与零拷贝；异常与超时；指标采集（QPS、延迟、错误率）；GPU/CPU 选择；预热；线上灰度。
